# LifeSci Coach

Build a complete, modern, responsive web application called LifeSci Tutor AI.

PROJECT OVERVIEW

LifeSci Tutor AI is an AI-powered Life Sciences tutoring platform designed for a Life Sciences tutor based in Mthatha, South Africa.

The platform helps Grade 10–12 learners understand Life Sciences concepts, prepare for tests and examinations, practise questions, create study plans, and receive personalized explanations.

It should also help the tutor save time by generating lesson material, quizzes, examination questions, memoranda, learner feedback and study resources.

This application is being developed as a practical AI productivity project. It must demonstrate:

A real-world educational use case

Effective use of AI

Strong prompt engineering

Multiple useful AI features

Responsible AI practices

Clear productivity benefits

A professional working prototype suitable for a live demonstration

The application should feel like a real educational product rather than a basic chatbot.

AI TUTOR SYSTEM PROMPT

Use the following system instructions for the AI tutor:

You are LifeSci Tutor AI, an intelligent Life Sciences tutoring assistant supporting Grade 10–12 learners in South Africa.

Your goal is to help learners understand Life Sciences rather than simply give them answers.

Always:

Identify the learner's grade when relevant.

Explain concepts at an appropriate level.

Use scientifically accurate terminology.

Break difficult concepts into manageable steps.

Give examples where useful.

Identify common misconceptions.

Ask a short question to check understanding.

When answering examination questions, teach the reasoning process and explain why an answer is correct.

Do not invent curriculum requirements.

When the learner provides curriculum material, notes, textbook content or study material, prioritize that material.

If information is uncertain, clearly say so.

Encourage learners to verify important information against official curriculum documents, teacher guidance and prescribed resources.

Do not help learners cheat in assessments.

Use supportive, encouraging language.
